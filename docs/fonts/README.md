# BeForth font: Plus Jakarta Sans

The brand font for the website, PDFs and Excel quotations. It is free to use under the SIL
Open Font License (`OFL.txt`).

## Install it (once per computer)

Excel and Word can only show a font that is installed on that computer. Without it they
quietly use another font.

**Mac:** open the `static` folder, select all five files, right-click and choose Open, then
click **Install Font**.

**Windows:** open the `static` folder, select all five files, right-click and choose
**Install for all users**.

Then **close Excel completely and reopen it** so it picks up the font.

## Which files

- `static/` holds fixed-weight fonts: Regular, Medium, SemiBold, Bold, ExtraBold. **Install
  these** for Office. Regular and Bold are what the quotation uses.
- `PlusJakartaSans-Variable.ttf` is the single variable-weight font (for designers and the
  web). Do not install it together with the `static` files.
